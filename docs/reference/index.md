# API Reference

The pages below are generated from public objects in `src/my_lib/`. Names exported from `my_lib` are the supported public API; `my_lib.logs` is supported for applications that install the `logs` extra.

| Module | Purpose |
|--------|---------|
| `my_lib.core.errors` | Define the library error hierarchy |
| `my_lib.core.example` | Build a greeting as an example API |
| `my_lib.logs.settings` | Define logging settings |
| `my_lib.logs.setup` | Configure console and file logging for applications |
| `my_lib.cli.settings` | Load command settings from the environment |
| `my_lib.cli.app` | Define the `my-lib` command |
| `my_lib.main` | Run the `my-lib` console script |
